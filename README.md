## The line

> The sock is not missing. It has been promoted to internal dust filter.

The excuse a robot vacuum gives after eating a sock: a deadpan corporate reframe — the sock was not eaten, it was promoted.

## How it works

`main.py` (Python 3, stdlib only) writes the single line to `/output/entry.txt`. The output is deterministic: the same 70 characters on every run. A `validate()` gate mirrors the bounty gate (1–200 UTF-8 characters, not only whitespace, one line).

Run it:

```sh
python3 main.py
cat /output/entry.txt
```
